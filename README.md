# 持久走ラボ

中学・高校の体育「持久走」（男子1500m／女子1000m）を、**ペアでのラップ計測 → 毎回の振り返り → 仮説の検証（探究）→ A3まとめ** までつなげる Web アプリです。
Google スプレッドシート＋Google Apps Script だけで動き、生徒は学校の Google アカウントで iPad などから使います。

## 主な機能

### 生徒
- **初回登録**：学年・組・番号・氏名・性別を自分で入力（Google アカウントとひも付け）
- **ペア計測**：自分の iPad をペアに渡し、周ごとにタップしてラップを記録
  - iPad を忘れた友達の記録を代わりに計測（友達の記録として保存）
  - ラップを押し忘れても「ここでゴール」で最終タイムだけは保存
- **計測直後の振り返り**：タイム・前回との差・新体力テストの得点を表示し、その場で感想を入力
- **探究ノート**：仮説 → ラップのデータで検証（ペース配分・練習回数）→ 結論・考察
- **A3横1枚のPDF**
  - 記録・振り返りシート（毎回の記録・ラップ・感想＋総括）
  - 探究レポート（仮説と検証のプロセス＋まとめ）
- 表示される得点は **新体力テスト（12〜19歳）の公式得点** のみ

### 教員
- **集計**：生徒一覧（ベスト・伸び・体力テスト得点・学校得点・振り返り率）、成績CSV出力、生徒ごとの詳細とA3シートPDF
- **ランキング**：中学全体／高校全体／学年別 × 自己ベスト・伸び率・最新、男女別、学年ごとの1位
- **分析**：得点分布、クラス比較、ペース配分と記録の関係、伸び率トップ
- **採点**：学校オリジナル得点表の編集（生徒には非表示）
- **設定**：教員アカウント、コースに合わせたラップ距離（初期値は1周100m：男子 `100x15`、女子 `100x10`）

## ファイル構成
| ファイル | 内容 |
|---|---|
| `Code.gs` | サーバー側（Apps Script）。シート作成・保存・権限チェック |
| `index.html` | 画面（生徒・教員）。Apps Script の外でブラウザで開くとサンプルデータのデモとして動きます |

## セットアップ
1. 学校の Google アカウントで新しいスプレッドシートを作成
2. 「拡張機能」→「Apps Script」を開く
3. `Code.gs` の内容を「コード.gs」に貼り付け
4. 「ファイル ＋」→「HTML」で `index` を作り、`index.html` の内容を貼り付け
5. 「プロジェクトの設定」でタイムゾーンを **(GMT+09:00) 日本標準時** にする
6. 関数 `setup` を実行して権限を許可（「設定・得点表・名簿・記録・仮説」のシートが作られます）
7. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**（学校ドメイン）内の全員**
8. 発行された URL を生徒と教員に配布（QRコードなど）。スクリプトの所有者は自動で教員になります

### 更新するとき
`Code.gs` と `index` を貼り替えて保存 →「デプロイ」→「デプロイを管理」→ 編集 →「新バージョン」→「デプロイ」（URL は変わりません）

## データ（スプレッドシートのシート）
| シート | 内容 |
|---|---|
| 設定 | アプリ名・教員メール・ラップ距離・採点に使う記録 |
| 得点表 | 学校オリジナル得点表 |
| 名簿 | email・学年・組・番号・氏名・性別（生徒の初回登録で追加。先生が先に入れておくことも可） |
| 記録 | 計測記録・ラップ・感想 |
| 仮説 | 探究ノートの仮説・考察、まとめ・総括 |

## 運用メモ
- 生徒の登録内容の修正は「名簿」シートで直接行う。行を削除するとその生徒は登録し直せる
- 同じ学年・組・番号を別のアカウントで登録しようとするとエラーになる
- 友達の代わりに計測できるのは、その友達が初回登録を済ませている場合のみ
- 生徒が記録を削除できるのは計測当日のみ（教員はいつでも）
- iPad に複数の Google アカウントでログインしていると開けないことがある（学校アカウント1つで使用）
- A3 の PDF 作成には html2canvas / jsPDF（cdnjs）を読み込みます。読み込めない場合は印刷画面から「PDFに保存」

## デモ
`index.html` をそのままブラウザで開くと、架空のサンプルデータで「初回登録／生徒の画面／教員の画面」を切り替えて試せます（保存はされません）。

## 注意
- 生徒の個人情報（氏名・記録）はスプレッドシートにのみ保存されます。リポジトリに名簿や記録を含めないでください
- 新体力テストの得点はスポーツ庁「新体力テスト実施要項（12歳〜19歳対象）」の項目別得点表（持久走）に基づきます（秒未満切り上げで判定）
